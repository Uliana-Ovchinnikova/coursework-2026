# Анализ бахадуровской эффективности критериев согласия

Репозиторий содержит отчётные материалы по курсовой работе.

**Тема работы:** Разработка численного метода оценки асимптотической эффективности критериев согласия по Бахадуру.

**Научный руководитель:** Гориховский Вячеслав Игоревич.

## Описание работы

Работа посвящена разработке численного метода оценки асимптотической эффективности критериев согласия по Бахадуру и его интеграции во фреймворк `pysatl-experiment` в виде нового типа эксперимента `bahadur_efficiency`.
